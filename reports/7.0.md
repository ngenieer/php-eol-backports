# PHP 7.0 backport verification report (2026-10-25)

- Base: php-7.0.33 (last release of the 7.0 branch)
- Source: this repository's 7.1 backport
- Patch: `patches/7.0/0001-CVE-2026-109618-109619-avoid-state-corruption-via-bailout.patch`

## Porting
The 7.1 backport applied almost unchanged. The parts handled by hand:

| File | Handling |
|---|---|
| Zend/zend_alloc.c | Added only `#include "zend_execute.h"` (7.0 has no zend_bitset.h). Replaced the overflow errors in `_estrdup`, `_estrndup` and `zend_strndup` with `zend_mm_safe_error_ex` |
| Zend/zend_hash.c | Replaced the 3 hash size overflow errors with `zend_mm_safe_error_ex` |
| Zend/zend_vm_def.h | 7.0 uses `zend_string_realloc` instead of `zend_string_extend`, so the length overflow check was inserted before it |
| Zend/zend_execute_API.c | Same approach as 7.1 (applied without conflicts) |
| Zend/zend_vm_execute.h | As for 7.1, only the difference between the regenerated unpatched and patched outputs (81 lines) was applied to the shipped file |
