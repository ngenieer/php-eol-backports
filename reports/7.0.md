# PHP 7.0 백포트 검증 보고 (2026-10-25)

- 기준: php-7.0.33 (7.0 브랜치 최종 릴리스)
- 원본: 이 레포의 7.1 백포트
- 패치: `patches/7.0/0001-CVE-2026-109618-109619-avoid-state-corruption-via-bailout.patch`

## 포팅 내용
7.1 백포트에서 거의 그대로 적용됐습니다. 수동 처리한 부분은 다음과 같습니다.

| 파일 | 처리 |
|---|---|
| Zend/zend_alloc.c | `#include "zend_execute.h"`만 추가(7.0에는 zend_bitset.h 없음). `_estrdup`·`_estrndup`·`zend_strndup`의 오버플로 오류를 `zend_mm_safe_error_ex`로 교체 |
| Zend/zend_hash.c | 해시 크기 오버플로 오류 3곳을 `zend_mm_safe_error_ex`로 교체 |
| Zend/zend_vm_def.h | 7.0은 `zend_string_extend` 대신 `zend_string_realloc`을 쓰므로 그 앞에 길이 오버플로 검사 삽입 |
| Zend/zend_execute_API.c | 7.1과 같은 방식(충돌 없이 적용) |
| Zend/zend_vm_execute.h | 7.1과 같은 방식으로 원본·패치본 재생성 결과의 차이(81줄)만 출시본에 적용 |
