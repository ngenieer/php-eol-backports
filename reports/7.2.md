# PHP 7.2 백포트 검증 보고 (2026-10-25)

- 기준: php-7.2.34 (7.2 브랜치 최종 릴리스)
- 원본: 이 레포의 7.3 백포트 (← php-src 7.4 공식 EOL 백포트 712e60f9ed)
- 패치: `patches/7.2/0001-CVE-2026-109618-109619-avoid-state-corruption-via-bailout.patch`

## 포팅 내용
7.3 백포트를 cherry-pick 했을 때 충돌이 난 7개 파일을 수동으로 해결했습니다. 종료 처리(zend_execute_API.c), 메모리 할당기(zend_alloc.c), 업로드 처리(rfc1867.c), SAPI.c, main.c는 그대로 적용됐습니다.

| 파일 | 처리 |
|---|---|
| Zend/zend_hash.c / .h | 7.2에는 `_zend_new_array_0`가 없어서, `zend_new_array_singleton()`을 7.2 API(`_zend_hash_init` 후 `nTableSize = 1`)로 새로 작성 |
| Zend/zend_API.h | 7.2 기존 `array_init` 정의 유지, `array_init_singleton` 매크로만 추가 |
| Zend/zend_types.h | 변경 없음. 원본 패치의 변경은 7.3+ SSE2 `HT_HASH_RESET`의 64바이트 미만 처리인데, 7.2는 memset만 사용하므로 1칸 해시도 그대로 안전 |
| Zend/zend_vm_def.h | 7.2의 do-while 구조 안에 CONCAT/FAST_CONCAT 길이 오버플로 검사 삽입 |
| Zend/zend_vm_execute.h | 7.2의 `zend_vm_gen.php`로 재생성 |
| main/php_variables.c | 7.2 코드 유지, GPC 배열 생성 4곳을 `array_init_singleton`으로 교체 |
| ext/session/session.c | 7.2는 `true`가 선언되지 않아 `|| true`를 `|| 1`로 표기 (같은 의미: 업로드 진행 기능 비활성) |
